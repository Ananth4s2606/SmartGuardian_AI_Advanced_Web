SmartGuardian AI — Advanced Website Prototype

HOW TO RUN (Windows)
1. Double-click index.html.
2. It opens in Chrome, Edge, or Opera. No installation or internet is needed.

FEATURES IN THIS DEMO
- Responsive dashboard with sample weekly chart and app usage
- Family profile cards; add fictional profiles
- Screen-time target and study/wind-down rules
- Toggleable reminder settings and a test reminder
- Weekly insights and CSV report export
- TrustLock security center (simulation)
- Light/dark theme and reset demo data

IMPORTANT LIMITATIONS
This is a front-end website prototype only. All usage figures are fictional sample data.
It does not connect to real phones, collect real screen time, send system notifications,
provide real login/authentication, use a database/cloud backend, block apps, or run a real AI model.
Do not enter real or sensitive personal information. Security center controls are illustrative,
not production security features.
